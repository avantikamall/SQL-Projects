# SmartMart Retail Order Analysis

## Project Overview
This SQL project analyzes retail products and customer orders for SmartMart Retail Pvt. Ltd. The objective is to understand product performance, sales quantity, customer purchasing patterns, supplier performance, and inventory levels.

## Database
- **Database Name:** `RetailAnalyticsDB`
- **Tables:** `items`, `orders`

## Key SQL Concepts
- Database and table creation
- Primary and foreign keys
- Filtering and sorting
- Aggregate functions such as `SUM()`, `COUNT()`, and `AVG()`
- `GROUP BY` and `HAVING`
- Joins and subqueries
- Business analysis and KPI reporting

## Business Analysis
The project covers product-wise and category-wise sales, payment-mode analysis, city-wise orders, supplier performance, stock analysis, products never ordered, and overall business KPIs.

## Tools Used
- MySQL
- SQL

## Objective
To practice SQL queries and derive useful business insights from retail product and order data.
