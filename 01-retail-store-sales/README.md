# Retail Store Sales Analysis using MySQL

## Project Overview

This project analyzes retail transaction data from a fictional Smart Retail Store using MySQL to understand sales performance, customer behavior, product performance, payment preferences, and salesperson performance.

## Business Objectives

- Analyze total and average sales
- Compare city-wise and state-wise revenue
- Evaluate product and category performance
- Analyze payment-mode usage
- Compare salesperson performance
- Identify customer purchasing patterns
- Generate key business KPIs

## Dataset

- 20 sample retail transactions
- Main table: `store_sales`

## SQL Concepts Used

`SELECT` • `WHERE` • `DISTINCT` • `ORDER BY` • `LIMIT` • `LIKE` • `BETWEEN` • `IN` • `COUNT()` • `SUM()` • `AVG()` • `MAX()` • `MIN()` • `GROUP BY` • `HAVING`

## Analysis Areas

**Sales:** Revenue, city-wise sales, state-wise revenue, monthly trends

**Customers:** Customer filtering, age analysis, repeat customers, payment behavior

**Products:** Product and category performance, quantity analysis

**Salesperson Performance:** Salesperson-wise revenue and maximum revenue

**Payment Analysis:** Payment-mode frequency and customer payment preferences

## KPI Report

| KPI | Description |
|---|---|
| Total Orders | Total number of transaction records |
| Total Revenue | Sum of final transaction amounts |
| Average Order Value | Average transaction amount |
| Highest Sale | Maximum transaction amount |
| Lowest Sale | Minimum transaction amount |

## Key Findings

Based on the sample dataset:

- Total Orders: 20
- Total Revenue: ₹649,500
- Average Order Value: ₹32,475
- Highest Sale: ₹57,000
- Lowest Sale: ₹8,500

> Findings are based only on the sample dataset used in this project.

## How to Run

1. Open MySQL Workbench.
2. Run `retail_store_sales_analysis.sql`.
3. Create the database and table.
4. Insert the sample data.
5. Execute the analysis queries and review the results.
